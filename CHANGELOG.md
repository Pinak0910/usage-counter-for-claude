# Changelog

## 1.0.0 (2026-11-03)

First public release.

- Usage line on the claude.ai chat box: session and weekly percentages with a colour-coded bar and a "Resets in hh:mm" countdown
- ⋯ menu with reset clock times, last reply cost, extra usage credits and Update now
- Optional alerts at 80%, 90%, at a limit and when a limit resets
- Toolbar badge and popup
- Updates only on events (page open, reply finished, tab revisited), never on a timer
